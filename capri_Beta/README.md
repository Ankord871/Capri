# Капри (всё с нуля)

Голосовой помощник для ПК. Нейросеть, обучение (backprop + Adam) и признаки звука написаны на чистом numpy,
без готовых моделей. Сторонние библиотеки: `numpy`, `sounddevice` (микрофон), `requests` (только для Telegram-бота). Окно рисуется встроенным в Python `tkinter`.

## Быстрый старт

```
pip install numpy sounddevice
python record_data.py        # записать голос: «Капри», команды, тишина, чужие слова
python train.py              # обучение; можно закрыть и запустить снова — продолжит с чекпоинта
python main.py               # Капри слушает и сидит на рабочем столе (окно HUD)
python main.py --terminal    # + мини-терминал в этой же консоли
```

Как говорить: «Капри» → «Готова тебя слушать» → короткая пауза → команда.

## Капри на рабочем столе

Окно без рамки поверх всех окон: только персонаж из `avatar/capri.gif` (прозрачный фон). В покое чуть прозрачна,
когда слышит «Капри» или говорит — становится плотной и двигается быстрее. Левая кнопка мыши — перетащить,
правая — «Выход». Настройки — `config.json`, раздел `hud`: `enabled`, `corner` (top_left / top_right / bottom_left /
bottom_right), `click_through` (окно не ловит клики), `image` (имя gif из папки `avatar/`).
В терминале: `hud on|off`, `hud corner bottom_left`. Без окна: `python main.py --no-hud`.
Анимация сделана из вашей картинки `avatar/capri.png` (плавание и качание волос/руки); если пришлёте свою анимацию
или кадры из аниме-сцены — положите gif в `avatar/` и впишите имя в `hud.image`.

## Обучение на опыте

Всё, что Капри услышала и на что отреагировала (проснулась / выполнила команду / не поняла), складывается в `inbox/`.
В терминале:

| Команда | Что делает |
|---|---|
| `inbox` | список услышанного: как поняла и насколько уверена |
| `play <№>` | прослушать запись |
| `fix <№> [команда]` | запись становится примером команды (без команды — как поняла; `_unknown` — «это что-то другое») |
| `drop <№>` | выбросить запись |

Затем `python train.py --more 20` — доучивание поверх чекпоинта (веса не сбрасываются).
`learning.auto_accept` в конфиге (0 = выкл., например 0.9) отправляет уверенно распознанное сразу в обучение — быстро,
но ошибки тоже закрепляются, включайте осознанно. Фразы, сказанные пока она «спит», и тишина не сохраняются.

## Больше команд

```
python terminal.py
capri> presets                       # список готовых команд
capri> preset screenshot calc time   # добавить сразу несколько (лучше по 3–5)
python record_data.py                # запишет только то, чего не хватает
python train.py --grow               # перенесёт выученное и доучит новые команды (старые не забываются)
```

Готовые команды: screenshot, desktop, close, prev, youtube, calc, notepad, taskmgr, explorer, downloads, time, date,
switch, newtab, closetab, refresh, fullscreen, screen_off. Свои: `add <имя> <действие> [цель]`
(действия — `actions`; `hotkey` принимает сочетание, например `add reopen hotkey ctrl+shift+t`),
сценарии из нескольких шагов — `scene`. Время и дата называются системным голосом (текст каждый раз новый).

## Мини-терминал

`list`, `set`, `add`, `preset`, `presets`, `scene`, `remove`, `phrase`, `reply`, `browser`, `home`, `hud`, `voices`, `run`,
`say`, `actions`, `inbox`, `play`, `fix`, `drop`, `exit`. Справка по любой: `help <команда>`.
Браузер: `browser brave` (общий), `browser opera music` (только для музыки), `browser default` — системный.

## Голос Капри

`python voices.py list` покажет, какие фразы нужны и каких файлов нет. Файлы `voices/<ключ>.wav`; новые команды используют
общий `ok.wav`. Нет файла — эту фразу произносит системный голос Windows (чужая запись вместо неё не подставляется). Одну длинную запись можно нарезать: `python voices.py split запись.wav`.

## Несколько ПК

Главный ПК: `python federated.py server` (напечатает токен и адрес).
Остальные: `python train.py --server http://IP_ГЛАВНОГО:8765 --token ТОКЕН --worker имя_пк`.
Каждый ПК учится на своих записях и шлёт веса после чекпоинта; главный усредняет (FedAvg), ПК забирают общую модель.
На всех ПК должен быть одинаковый `config.json` (список команд) и одинаковая версия кода. Передача по HTTP — только
домашняя сеть или VPN, не открывайте порт в интернет.

## Telegram

`python telegram_bot.py --token ТОКЕН --allow ВАШ_CHAT_ID` (или id в `telegram_allowed.txt`). Бот управляет ПК, поэтому
слушается только чатов из списка; остальным отвечает «Доступ закрыт» и показывает их chat id (так узнаете свой).
Токен хранится в `telegram_token.txt` — никому не отправляйте этот файл. Нужны `requests` и `ffmpeg`.

## Файлы

`audio_features.py` признаки · `nn.py` сеть · `common.py` конфиг и чекпоинты · `train.py` обучение (`--more`, `--grow`,
`--fresh`) · `federated.py` сервер/клиент · `record_data.py` запись · `listener.py` микрофон · `assistant.py` логика ·
`actions.py` действия · `tts.py` речь · `terminal.py` терминал · `hud.py` окно с персонажем · `learn.py` inbox ·
`voices.py` голос · `telegram_bot.py` · `main.py` · `selftest.py` самопроверка (`python selftest.py`, ~3 мин).

## Честные ограничения

- Это распознавание набора команд под ваш голос, не понимание речи. Новые фразы требуют записей (30–50 на команду).
- Окно (tkinter, прозрачность, флаги Windows), микрофон и звук проверить вне вашего ПК нельзя: `selftest.py` проверяет
  логику и рисование окна в картинку, но не живое окно.
- Встроенный аватар — оригинальный рисунок, не персонаж из аниме.
